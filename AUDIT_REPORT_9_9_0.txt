IKIGAI WORLD 9.9.0 — FULL PACKAGE AUDIT
======================================

Base package: ikigaithunghiem-main (2)(1).zip
Focus: mobile-first stability, especially portrait iPhone orientation.

AUDIT FINDINGS
--------------
1. CSS contained accumulated mobile overrides from 9.8.0, 9.8.2 and 9.8.5.
   The room root was assigned both rotate(90deg) and rotate(-90deg).
   The map's portrait layout uses rotate(90deg). This mismatch caused rooms
   to appear 180 degrees opposite to the map.
2. CSS had accumulated repeated selectors and a duplicated v8 map-stage block.
   The identical map-stage block and obsolete mobile rotation/geometry rules were
   removed. Other component-specific cascade rules were retained where they still
   control distinct board, room, actor, or seat states; mass deletion would risk
   changing desktop and room styling.
3. HTML had no duplicate IDs and all local src/href assets resolved.
4. JavaScript files passed Node syntax checks.
5. CSS parsed without syntax errors.
6. JSON question bank parsed successfully.
7. Supabase schema was retained unchanged.
8. Two 1-byte unused placeholder files were removed:
   assets/audio/sdsd and assets/buildings/fgh.
9. No referenced image/audio assets were removed.

CHANGES IN 9.9.0
----------------
- One authoritative portrait-phone room rotation: rotate(90deg), matching map.
- Landscape phone rooms explicitly remain unrotated.
- Removed an obsolete 9.6.0 portrait classroom override.
- Removed the duplicated v8 map-stage block.
- Empty chairs no longer render 'Chỗ trống' tags; occupants alone get avatar/name.
- iOS Safari transform prefix included.
- Consolidated room viewport sizing and header/interior geometry.
- Mobile buttons/board choices receive larger touch targets.
- Inputs use 16px on mobile to prevent iOS automatic zoom.
- Minimum 42px touch target for room controls and board choices.
- Removed maximum-scale=1 and user-scalable=no so accessibility zoom works.
- Updated asset cache versions to 9.9.0.
- Preserved app logic, Supabase URL/public publishable key, schema, bank,
  room art, characters, audio manager and audio assets.
