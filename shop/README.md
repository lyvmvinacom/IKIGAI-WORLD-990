# IKIGAI EDUCATION · Shop interface

Live game includes the Shop and Character/Bag map buttons and the landscape interface, using 24 VIP character images, 10 pet images, and 10 existing free characters.

The interface is a preview with 35,000 test coins. Purchases and equipment are saved only in browser-tab sessionStorage under ikigai-shop-demo. It does not read or write account wallets, inventories, EXP, learning progress, or live world avatars. No production purchase or equipment RPC is connected. Closing the tab ends this preview session.

Server schema drafts and isolated SQL tests remain on ikigai-shop-stage2. No SQL migrations or live catalog activation are included in this release.
